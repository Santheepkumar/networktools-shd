# Straw Hat Devs Brand Kit

This kit is built around the approved angled 3D Code Crown logo.

## Recommended use

- Primary logo: 01-Logo-Suite/primary-horizontal-light.svg
- Dark backgrounds: 01-Logo-Suite/primary-horizontal-dark.svg
- YouTube avatar: 04-Social/youtube-avatar-800.png
- Small icons: 01-Logo-Suite/icon-flat.svg
- One-color print: monochrome files in 01-Logo-Suite
- Brand rules: 06-Guidelines/StrawHatDevs-Brand-Guidelines.pdf
- Video intro: 05-Intro/strawhatdevs-intro-dissolve.mp4

The wordmark text in the final logo SVGs is converted to vector paths, so no font installation is required.
